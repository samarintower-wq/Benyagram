# Беняграм

Полноценный стартовый проект мессенджера: регистрация/вход, общий чат, WebSocket-обновления сообщений, контекстное меню (ответ, копирование, изучение метаданных, закрепление, редактирование и удаление своих сообщений), помощник Groq по префиксу `AI`, карта мира MapLibre со спутниковыми тайлами Esri и 3D-рельефом AWS Terrain Tiles, погода OpenWeather, сохранение пользователей и сообщений в MongoDB.

## Render
Build command: `pip install -r requirements.txt`
Start command: `uvicorn main:app --host 0.0.0.0 --port $PORT`

Environment Variables:
- `MONGODB_URI` — MongoDB connection string. Database: `benyagram`.
- `GROQ_API_KEY` — включает ответы помощника при сообщении `AI твой вопрос`.
- `OPENWEATHER_API_KEY` — поиск мест и погода на карте.
- `APP_SECRET_KEY` — длинная случайная строка для подписи сессий; задай свою в Render.

## Примечания
Для постоянной работы на нескольких инстансах нужна MongoDB и общий механизм рассылки (например, Redis pub/sub); текущий WebSocket broadcast обслуживает подключения к одному инстансу. Временное хранилище без MongoDB предназначено только для теста и сбрасывается при перезапуске. HTTPS на Render обязателен для безопасной cookie. Это стартовая версия: прежде чем открывать публичную регистрацию широкой аудитории, добавьте лимиты запросов, модерацию, восстановление пароля, блокировки и правила хранения данных.
